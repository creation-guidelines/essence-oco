# Essence

**How to say why and how - of anything.** Four questions - why does this exist, what must it reach, how is
each step delivered and proven, what is actually happening - each leading to the next.

- [ESSENCE.md](ESSENCE.md) - the method, with the test of a good answer for each question.
- [`data/`](data) - this project's own essence, written with the method alone.

Part of the [Open Commons Observatory](https://open-commons-observatory.github.io/), which draws every project's essence on one page.
